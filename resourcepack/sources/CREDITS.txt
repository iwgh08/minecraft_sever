This is the resource pack of a small private Minecraft server. It combines two packs:

1. NMinimap resource pack
   Generated by the NMinimap plugin 1.0.9-quickfix-1 (by NezuShin) from the server's config.
   Files: assets/nminimap/ and the nminimap_* overlay folders
   License: GNU GPL v3.0, see LICENSE-NMinimap-GPL-3.0.txt
   Source: https://github.com/NezuShin/NMinimap

2. NoMod Shaders 0.6.0, resource pack part
   By The Mod Hunter (youtube.com/@themodhuntergg)
   Files: assets/minecraft/shaders/ and assets/modhunter/
   License: MIT, see LICENSE-NoModShaders.txt
   Download: https://www.curseforge.com/minecraft/texture-packs/nomod-shaders

Only pack.mcmeta was rewritten so that one file can describe both packs.
Every other file is unchanged from the two packs above.
